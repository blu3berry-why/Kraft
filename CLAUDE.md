# Kraft — agent instructions

## Commit attribution

This repo keeps AI attribution: commits end with the `Co-Authored-By:` trailer and PRs with the generation footer, as the harness adds them. The `no-ai-attribution` skill (from `workflow@blu3berry-skills`, enabled here for `/retro`) does **not** apply in Kraft. Do not strip the trailers, and do not add its `attribution` block to `.claude/settings.json`.
